# Run & review the command

1. Pick a tool and fill in its form.
2. Review the **exact command** the toolbox will run — nothing runs until you say so.
3. **Run** — captured output streams back as logs and parsed tables, or opens an
   integrated terminal for interactive tools (listeners, shells, `sudo`).

Missing a dependency? A red badge shows what's not installed, with a one-click
copy of the install command.
